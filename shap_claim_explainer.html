Upload a claim SHAP file to begin

This tool reads your Excel file, identifies SHAP values per feature, and generates a plain-language explanation for each claim — covering what drove the score, which category it falls into, and what an auditor should check.

Expected column format:
  • One column for claim_number (or claim_id, claimid)
  • One column for score (or risk_score, probability)
  • SHAP columns named like shap_drgcode, shap_los, shap_provider etc.
  • Optional feature value columns: drgcode, losgm_ratio, providertaxid, discharge_status, mcc_count, cc_count, primary_diag, procedure_code

Column names are case-insensitive. SHAP columns are auto-detected by the shap_ prefix or matched to known feature names.
